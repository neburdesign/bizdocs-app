# BizDocs App — Angular starter

Primeiro ecrã implementado a partir do frame Figma `3332:14188` (Pedidos de aprovação).

## Requisitos
- Node.js 20.19+ ou 22.12+
- npm

## Executar
```bash
npm install
npm start
```
Abrir http://localhost:4200

## Build
```bash
npm run build
```

## O que já funciona
- Dropdown do ícone de utilizador com os cinco filtros de origem/responsável.
- Dropdown do ícone de filtro com Em aprovação, Aprovados e Rejeitados.
- Combinação dos dois filtros e pesquisa textual.
- Cards superiores em scroll horizontal.
- Favoritos e ações demonstrativas por documento.
- Navegação inferior demonstrativa.

## Nota
Esta primeira entrega usa dados locais de demonstração. Ainda não existe ligação a API, autenticação, armazenamento persistente ou serviços reais BizDocs. A imagem e estrutura visual foram interpretadas a partir do frame Figma; os ícones/logótipo são aproximações temporárias, a substituir pelos assets oficiais exportados do design.
